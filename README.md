# gradecheckコマンド

![test](https://github.com/yutaro-fujii/robosys2026/actions/workflows/test.yml/badge.svg)

合格基準に達するために、残りの試験や課題で必要となる得点を計算するコマンドです。

中間試験、レポート、小テスト、出席点など、任意の評価項目に対応しています。
複数科目の一括計算も可能です。

## インストール方法

```bash
$ git clone https://github.com/yutaro-fujii/robosys2026.git
$ cd robosys2026
```

## 使用方法

標準入力から以下の形式で入力します。

```
科目名,合格基準,評価項目名,得点,配点割合,...
```

得点と合格基準は100点満点換算、配点割合は百分率で指定します。
評価項目は任意の個数を指定できます。

入力されていない評価項目の配点は、100%から入力済みの配点の合計を引いた値となります。

### 必要得点の計算

中間試験35%、演習30%、期末試験35%の科目で、
中間試験が51点、演習が100点、合格基準が60点の場合です。

```bash
$ echo "センサ工学,60,中間,51,35,演習,100,30" | ./gradecheck
センサ工学,35
```

期末試験で35点以上を取れば、合格基準に達します。

### 既に合格基準に達している場合

```bash
$ echo "科目A,60,中間,80,80" | ./gradecheck
科目A,PASS
```

### 満点でも合格基準に達しない場合

```bash
$ echo "科目B,60,中間,20,80" | ./gradecheck
科目B,IMPOSSIBLE
```

### 複数科目の一括計算

```bash
$ printf "科目A,60,中間,40,50\n科目B,60,中間,70,50\n" | ./gradecheck
科目A,80
科目B,50
```

同じ入力形式のデータをテキストファイルに保存して利用することもできます。

```bash
$ ./gradecheck < grades.txt
```

### 不正な入力

```bash
$ echo "科目A,60,中間,-10,50" | ./gradecheck
Error: 1行目: 数値は0から100の範囲で入力してください
```

エラーメッセージは標準エラー出力に表示されます。

## 出力形式

標準出力には科目名と計算結果をカンマ区切りで出力します。

- 数値: 残りの評価項目で必要な加重平均得点を整数に切り上げた値
- `PASS`: 既に合格基準に達している
- `IMPOSSIBLE`: 残りの評価項目で満点を取っても合格基準に達しない

正常終了時の終了ステータスは0です。
不正な入力がある場合は1を返します。

複数行の入力に不正な行が含まれていても、正常な行の計算は継続します。

## 計算方法

入力済みの評価項目について、得点と配点割合の積を100で割り、その合計を現在の得点とします。

残りの配点割合から、合格基準に達するために必要な得点を計算します。

必要得点 = (合格基準 - 現在の得点) × 100 / 残りの配点割合

計算結果は整数に切り上げます。

## 注意事項

- 得点、配点割合、合格基準は0から100の範囲で指定してください。
- 配点割合の合計は100%以下としてください。
- 得点や配点割合には小数も使用できます。
- 科目名や評価項目名にカンマは使用できません。
- 出席日数や試験ごとの最低得点など、点数以外の合格条件は考慮していません。
- 実際の単位取得条件は各科目の評価基準を確認してください。
