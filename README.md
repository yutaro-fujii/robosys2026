
# gradecheck・plusコマンド

![test](https://github.com/yutaro-fujii/robosys2026/actions/workflows/test.yml/badge.svg)

## gradecheckコマンド

大学などの授業において、合格基準に達するために
今後の試験や課題で必要となる得点を計算するコマンドです。

中間試験、レポート、小テスト、出席点など、
得点が判明している評価項目から必要な得点を計算します。

科目ごとに異なる評価方法や配点割合に対応しており、
複数科目をまとめて計算することも可能です。

## 開発背景

大学の授業では科目ごとに成績の評価方法が異なるため、
期末試験などで何点取れば単位を取得できるのかを
計算する必要がありました。

この計算を簡単に行えるようにするため、
本コマンドを開発しました。

## インストール方法

以下のコマンドを実行してください。

```bash
git clone https://github.com/yutaro-fujii/robosys2026.git
cd robosys2026
```

## 使用方法

標準入力から、以下の形式でデータを入力します。

```
科目名,合格基準,評価項目名,得点,配点割合,...
```

得点と合格基準は100点満点換算、
配点割合は百分率で入力してください。

評価項目は任意の個数を指定できます。
入力されていない評価項目の配点は、
100%から入力済みの配点を引いた値となります。

### 実行例1：必要得点の計算

```bash
echo "センサ工学,60,中間,51,35,演習,100,30" | ./gradecheck
```

実行結果：

```
センサ工学,35
```

残りの評価項目で必要な平均得点は35点です。

### 実行例2：合格基準に達している場合

```bash
echo "科目A,60,中間,80,80" | ./gradecheck
```

実行結果：

```
科目A,PASS
```

### 実行例3：満点でも合格基準に達しない場合

```bash
echo "科目B,60,中間,20,80" | ./gradecheck
```

実行結果：

```
科目B,IMPOSSIBLE
```

### 実行例4：複数科目の一括計算

```bash
printf "科目A,60,中間,40,50\n科目B,60,中間,70,50\n" | ./gradecheck
```

実行結果：

```
科目A,80
科目B,50
```

ファイルに保存したデータも入力できます。

```bash
cat grades.txt | ./gradecheck
```

### 実行例5：不正な入力

```bash
echo "科目A,60,中間,-10,50" | ./gradecheck
```

エラーメッセージは標準エラー出力に表示されます。

## 出力形式

- 数値：残りの評価項目で必要な加重平均得点（整数に切り上げ）
- PASS：既に合格基準に達している
- IMPOSSIBLE：残りの評価項目で満点を取っても合格基準に達しない

正常終了時の終了ステータスは0です。
不正な入力がある場合は1を返します。

複数行の入力に不正な行が含まれる場合でも、
正常な行の計算は継続します。

## 注意事項

- 得点、配点割合、合格基準は0から100の範囲で入力してください。
- 入力済みの配点割合の合計は100%以下としてください。
- 得点や配点割合には小数も使用できます。
- 科目名や評価項目名にカンマは使用できません。
- 出席日数や試験ごとの最低得点など、個別の合格条件は考慮していません。
- 実際の単位取得については各科目の評価基準を確認してください。

## plusコマンド

標準入力から読み込んだ数字を足し合わせるコマンドです。

### 実行例

```bash
seq 5 | ./plus
```

実行結果：

```
15
```
